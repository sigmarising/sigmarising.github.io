### 本质复杂度依然在于人与人

看完了前一阵很火的《置身钉内》，越来越感觉到它再次印证了[我之前的观点](/posts/20260512-tech-my-ai-agent-memo)：
- AI 只是解决了偶然复杂度的问题，即工具的迭代
- AI 永远无法解决**人与人之间**的本质复杂度问题

### 为何我厌恶毫无意义的 996 加班

古人云：一鼓作气，再而衰，三而竭。

不是不能接受偶尔为了 MileStone 冲刺的短暂目标；但如果天天都有 MileStone 让大家克服一下配合加班，**那说明所有的目标都不重要**。

持久加班除了培养工贼，转移阶级矛盾外，没有任何作用。

梁文峰认为人的一天精力就只有 7 小时可以专注工作，国家领导人的 G20 峰会也两天就完事。而那些设置违反人性制度的公司，只会促进员工的注意力放在那些制度制定者初衷更不希望看到的地方。

### 大陆外企的国人老登是真的挺多的

有一位曾上学时候关注了很久的某外企知乎大 V，在我工作多年后，因为他关于数学丁真的离谱发言光速取关。

前一阵，又想看看他签了 MCN 后的 AI 观点是不是有什么独特的视角，但结果没过两周就因为他错误百出的离谱前后登味十足的发言再次取关。

不知道是不是因为这位大 V 老师成功活过了国区近 90% 裁员 + 的确到了岁数上了年纪了，那种“老登”味的点评和一些“老登味判断的事实错误”实在是令真实相关行内从业的年轻人难顶（我也承认我可能有点以偏概全，毕竟这位老师还是有 35% 左右的观点我还是认同的；但既然如此，保持路人就好）。

再加上我之前曾在 MS CN 三年观察过不少的“登味十足的中/老登”，不得不说，CN 区的这些外企，国人“登”的数量还是太多了。

### 前端的确已经死掉了

AI Coding 击碎 2025 和 2026 之后，如今，几乎没人再争论 React Vue 谁优谁劣了。

果然，前端的确已经死掉了。

### OpenAI 似乎完全不 Care Harness 2B 的 Solution

相比于 Claude Code 可以轻松的配置个人订阅/Gateway/Bedrock/Vertex/Foundry 模型接入，CodeX 对于非官方 Gateway 的接入堪称完全的不上心和窒息。

CodeX 不仅逆天的 TOML 配置项左右脑互搏（你甚至不知道到底是哪个配置文件里的哪个配置项真正生效，而且哪个配置项这两个 CodeX 版本好使下两个 CodeX 版本就寄了）、默认藏起来 Context Window 显示、AskUserQuestion 竟然会超时自动帮选而非阻塞进程、订阅用户阻止最新模型的 1M 上下文访问、非官方 Gateway 突破 1M Context 的配置手段更是丑陋的惊为天人……

层层混乱 + 层层阻碍，似乎都显露出 OpenAI 对于 Harness 2B 的完全不上心（毕竟重置额度都是 Only 针对 2C 用户的）。至少截止到目前，OpenAI 的 CodeX 在 2B 领域给我的感觉是纯纯一坨。

OpenAI 和 A/ 的 LLM Service 都在单卖，但在 Harness 上，我只看到了 CodeX 在 2B 上的完全投降，以及大量培养 2C 水军的倾向（至少目前如此）。
